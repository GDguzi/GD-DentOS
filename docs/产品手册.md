# 产品手册 · GD · DentOS

> 给诊所使用者看的说明书。不写代码、不讲原理，只讲"怎么用"。
> 技术安装细节见 [README](../README.md)；AI 病历草稿接口见 [开源发布_AI草稿接口.md](开源发布_AI草稿接口.md)。

## 一、装好第一次打开

### Windows 一键版（推荐，不用装任何东西）

> 从头到尾大概 3 分钟。中间会遇到 2 个 Windows 的拦截提示，**这是正常的**，下面每一步都写了怎么过。

#### 第 1 步：下载

打开本项目的**发行版**页面，下载 `good-dental-clinic-windows.zip`（也可以直接下 `good-dental-clinic.exe`，两者一样）：

- Gitee（国内，打得开、下得快）：<https://gitee.com/gubaoye/GD-DentOS/releases/latest>
- GitHub：<https://github.com/GDguzi/GD-DentOS/releases/latest>

> 页面上还有两个 `Source code`，那是源代码包，**不用下**——里面没有可以双击运行的程序。

#### 第 2 步：解压

右键压缩包 → **全部解压缩**。建议解压到 **D 盘新建一个文件夹**（比如 `D:\诊所系统`）。

> ⚠️ **别放在桌面或"下载"文件夹**——以后你的患者数据也都在这个文件夹里，
> 放桌面容易误删，重装系统也容易丢。

#### 第 3 步：双击运行，过掉两个拦截提示

双击 `good-dental-clinic.exe`。会遇到：

**① 蓝色大框「Windows 已保护你的电脑」**

这是因为本软件是免费开源的，没有花钱买微软的数字签名证书，**不代表有病毒**。

> 点框里的小字 **「更多信息」** → 下面会出现 **「仍要运行」** 按钮 → 点它。

**② 防火墙提示「是否允许此应用通信」**

如果你以后要让 iPad/手机连，勾上 **「专用网络」** 再点允许；只在这台电脑上用，直接点「取消」也不影响。

> 如果电脑装了 360、火绒等安全软件，可能会拦截或"清理"这个程序。
> 请在安全软件里把整个 `D:\诊所系统` 文件夹加进**信任/白名单**。

#### 第 4 步：记下第一次的密码

会弹出一个**黑色窗口**，里面写着：

```
  ★ 首次启动已建管理员：admin / 一串随机密码   （请尽快登录后改密）
    凭据也已存到 data/.admin_initial_password
```

**把这串密码抄下来或拍张照。** 万一没记住也不要紧——它存在
`data` 文件夹里名叫 `.admin_initial_password` 的文件里，**右键 → 打开方式 → 记事本** 就能看到。

#### 第 5 步：开始用

浏览器会**自动打开**登录页（没自动打开就手动输 `http://127.0.0.1:8765`），
用 `admin` + 刚才那串密码登录。

> 🔴 **登录后第一件事**：到「配置管理 → 人员与权限 → 账号管理」把密码改成你自己好记的。

#### 以后每天怎么开

**双击那个 `good-dental-clinic.exe` 就行**，跟第一次一样，但不会再弹拦截提示了。

- **黑窗口不能关**——它就是这个系统本身，关了系统就停了。可以把它**最小化**。
- 觉得每天双击麻烦：右键 exe → **发送到 → 桌面快捷方式**，以后点桌面图标就行。

#### 几个常见状况

| 情况 | 怎么办 |
|---|---|
| 黑窗口一闪就没了 | 多半被安全软件拦了，把文件夹加进白名单再试 |
| 浏览器显示"无法访问" | 看黑窗口里打印的网址，端口可能不是 8765（8765 被占用时会自动换一个） |
| 不小心关了黑窗口 | 重新双击 exe 即可，数据不会丢 |
| 想换台电脑用 | 把整个文件夹拷过去，双击 exe，数据原样都在 |

#### 数据在哪、怎么备份

**你所有的患者资料、病历、收费记录，全都在 exe 旁边的 `data` 文件夹里。**

> 📦 **备份方法**：把整个 `data` 文件夹拷到 U 盘或移动硬盘 = 完整备份。
> **建议每周拷一次**，换着两个 U 盘轮流用。

### 首次启动的三件事

1. **填诊所名**：首次登录会弹窗请你填写诊所名称（显示在登录页、病历卡、打印单头上）。
2. **建人员**：进「配置管理 → 人员与权限 → 人员 → 添加人员」，把医生/护士/前台录进去；
   需要登录系统的，在「账号管理」给他们开通账号。
3. **配基础数据**：「配置管理 → 全店设置」填营业时间、诊室；
   「收费项目」里按自家价目表调整。

## 二、每天怎么用（前台/医生动线）

### 患者来了

1. **新患者**：「患者管理 → 新增患者」填姓名电话即可（macOS 上可点「拍照识别」，
   拍身份证/登记表自动填字段）。
2. **挂号**：搜到患者 → 点进档案 → 左卡片点「挂号」（今天 09:00 起）。
3. **分诊**：点「分诊」选医生、诊室、初复诊，进候诊队列。

### 看病中（医生）

- 「今日工作」看候诊队列，点患者进档案。
- **写病历**：档案 → 「病历」→ 新建，主诉/检查/诊断/处置逐项填（牙位点十字格）。
- **划价**：「处置」里新建处置单，选处置项目自动生成收费单。

### 收费

- 「收费」tab 或「今日工作 → 待缴费」，选支付方式收款；退费在收费单详情里操作。
- 日结：「数据报表」里看当天收入、支付方式分布。

### 预约与回访

- **预约**：患者卡或「预约管理」新建，排班表可拖拽改时间。
- **回访**：患者卡点「**回访**」一键新建待回访计划；
  到期回访在「客户通」里统一处理、登记结果。

## 三、隔段时间要做的

### 备份（重要！）

- 内置备份：「配置管理 → 数据备份」做整库快照，建议**每周一次**。
- 更保险：定期把整个 `data` 文件夹拷到 U 盘/移动硬盘。
- 恢复：用快照覆盖回 `data` 目录即可（先停服务）。

### 让 iPad / 手机一起用（局域网）

一键版**默认只有这台电脑能打开**。想让同一个 WiFi 下的 iPad / 手机也能用
（患者签知情同意书、医生查房看病历），照下面做一次就行。

#### 做一个"局域网启动"的快捷方式

1. 在 exe 所在的文件夹里，**右键 → 新建 → 文本文档**。
2. 打开它，把下面两行**原样粘进去**：

   ```bat
   set DENTAL_LOCAL_ONLY=0
   start good-dental-clinic.exe
   ```

3. 点「文件 → 另存为」，文件名填 **`局域网启动.bat`**，
   保存类型选 **「所有文件」**（这一步很关键，否则会存成 .txt 用不了）。
4. 以后要让 iPad 连，就**双击这个 `局域网启动.bat`**；只自己用，还是双击原来的 exe。

#### 然后在 iPad 上打开

- 黑窗口里会多打印一行局域网网址，形如 `http://192.168.x.x:8765`，
  在 iPad 浏览器里输这个地址。
- iPad 第一次连会要一个**访问口令**（防止同 WiFi 的外人乱进）。
  口令在 `data` 文件夹里的 `.lan_password` 文件里，**右键 → 记事本**打开就能看到。

> 💡 iPad 打开后可以点浏览器的「分享 → 添加到主屏幕」，
> 桌面上就有个图标，用起来跟 App 一样。

> ⚠️ 前提是电脑和 iPad **连的是同一个 WiFi**。电脑用网线、iPad 用 WiFi 也行，
> 只要是同一个路由器就可以。

### 后台运行 & 开机自启（可选，用熟了再开）

黑窗口看着碍事？可以让系统隐身在后台跑，还能开机自动启动。

> ⚠️ 藏了窗口就看不到报错和启动信息了。**首次安装、升级、排查问题时别用后台方式**，
> 老老实实看着黑窗口跑；日常用熟了再开。

#### 做一个"后台启动"脚本

1. 在 exe 所在的文件夹里，**右键 → 新建 → 文本文档**，打开，把下面三行**原样粘进去**：

   ```vbs
   Set sh = CreateObject("Wscript.Shell")
   sh.CurrentDirectory = CreateObject("Scripting.FileSystemObject").GetParentFolderName(WScript.ScriptFullName)
   sh.Run "good-dental-clinic.exe", 0
   ```

2. 点「文件 → 另存为」，文件名填 **`后台启动.vbs`**，保存类型选 **「所有文件」**
   （和前面 .bat 一样的坑，存成 .txt 就用不了）。
3. 双击它：不会有任何窗口，等几秒，浏览器打开 `http://127.0.0.1:8765`
   能看到登录页，就是跑起来了。

- 想**后台 + 局域网**一起开：把第三行换成
  `sh.Run "cmd /c set DENTAL_LOCAL_ONLY=0 && good-dental-clinic.exe", 0`
- 想**停掉**：按 `Ctrl + Shift + Esc` 打开任务管理器，找到 `good-dental-clinic.exe`，结束任务。

#### 开机自动启动

1. 按 `Win + R`，输入 `shell:startup` 回车，会弹出「启动」文件夹。
2. 右键 `后台启动.vbs` → **发送到 → 桌面快捷方式**，再把桌面上那个**快捷方式**拖进「启动」文件夹。
   > ⚠️ **别把 `后台启动.vbs` 本体复制进去**——脚本是按"我自己在哪个文件夹"去找 exe 的，
   > 本体挪走了就找不到 exe，开机等于没启动。必须放**快捷方式**，让脚本本体留在原处。
3. 以后一开机它就自己在后台跑，打开浏览器输网址直接用。不想自启了，从这个文件夹删掉即可。

### 演示数据（给试用的人）

> 🔧 **这一节是给会用命令行的人看的**（源码方式运行）。
> 用 Windows 一键版的话**直接跳过**——想试功能，新建几个假患者自己点点就行，
> 想清空重来，把 `data` 文件夹删掉重启即可（⚠️ 正式用起来之后千万别这么干）。

```bash
python3 -m local_app.demo.seed_demo          # 生成 100 个合成假患者的演示库
DENTAL_DB=local_app/data/demo/demo_clinic.sqlite3 DENTAL_IMAGES=local_app/data/demo/images \
  DENTAL_PORT=8770 python3 -m local_app.run_local
```

演示库与正式库完全隔离，随便删改。演示数据全部是程序合成的，与任何真实患者无关。

## 四、功能地图

| 模块 | 在哪 | 干什么 |
|---|---|---|
| 今日工作 | 左侧导航 | 候诊队列、今日 KPI、工作检查 |

| 病历/处置/计划 | 患者档案内 | 临床文书、划价、治疗计划、口腔检查、手术、知情同意书 |

| 会员 | 患者档案内 | 储值充卡、消费、退现 |
| 库存管理 | 左侧导航 | 物品、供应商、出入库、盘点 |
| 消毒管理 | 左侧导航 | 器械消毒批次追溯 |
| 技工单 | 患者档案内 | 外加工单全流程 |
| 数据报表 | 左侧导航 | 收入、日结、收银、业绩、欠款 |
| AI 草稿箱 | 左侧导航 | 审核外部生成的病历草稿（不配 AI 时空态） |
| 配置管理 | 左侧导航 | 全店设置、人员与权限、收费项目、操作历史、回收站、数据备份 |

## 五、数据安全底线

- 所有数据只存在你自己的电脑上（SQLite 单文件 + 影像文件夹），不上云、不联网也能用。
- 日志不含患者明细；患者数据目录已被版本库排除，永远不会被上传。
- 医疗文书合规（病历书写规范、知情同意书效力）请按当地法规自查。
