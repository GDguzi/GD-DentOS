# 常见问题解答（FAQ）

> 用不上的时候没人看，出问题的时候才来翻——所以每条都直接给做法。
> 覆盖：安装启动、账号登录、数据备份迁移、局域网、打印、升级、拍照识别、AI 草稿箱。

## 安装与启动

**Q：双击 exe 黑窗口一闪就没了？**
A：八成是端口被占了（已经有一个实例在跑）。先看浏览器能不能直接打开
`http://127.0.0.1:8765`；能打开说明系统已经在运行。不是的话，在黑窗口里看报错：
默认 8765 被占时启动器会自动换一个端口并打印出来。

**Q：杀毒软件/Windows SmartScreen 报警？**
A：PyInstaller 打的单文件 exe 是业内常见的误报对象（没买代码签名证书）。
选"仍要运行"即可；源码全部公开，不放心可以自己从源码跑（README 快速开始）。

**Q：Mac 能用吗？**
A：能。Mac 上没有一键 exe（一期只做 Windows），用源码方式：
`pip install -r requirements.txt && python3 -m local_app.run_local`，两步搞定。
Mac 还独占「拍照建档」功能（用系统自带 Vision 识别，照片不出本机）。

## 账号与登录

**Q：忘记管理员密码怎么办？**
A：本机自救——停掉服务，打开数据目录里的数据库（ clinics.sqlite3 ），
把 `users` 表里你的账号记录删掉，重启服务，系统会重建初始管理员（admin / admin）。
（数据目录：Windows 在 exe 同级 `data/`；源码版在 `local_app/data/`。）
不会操作的话，找给你们部署的人来做，一分钟的事。

**Q：首次登录的账号密码是什么？**
A：账号 `admin`、密码 `admin`。登录时系统会提醒你尽快修改。
**要让 iPad/手机上局域网连之前，请务必先改掉默认密码**——默认口令
一旦开了局域网就等于人人可登。改密入口：「人员与权限 → 账号管理」。

**Q：员工也要登录吗？**
A：要。每次操作都记录到人（操作历史可查），出了纠纷能溯源。
在「人员与权限 → 账号管理」给员工开账号，权限按角色（医生/护士/前台…）勾选。

## 数据、备份、换电脑

**Q：我的数据存在哪？**
A：全在数据文件夹里：Windows 一键版在 exe 同级 `data/`；源码版在 `local_app/data/`。
核心是一个 SQLite 文件 + 影像文件夹。**整个文件夹拷走 = 完整备份。**

**Q：换新电脑怎么迁移？**
A：旧电脑停服务 → 拷走整个 `data` 文件夹 → 新电脑装好系统 → 把 `data` 放回原位
→ 启动。患者、病历、收费、设置全部原样回来。

**Q：要联网吗？数据会不会被上传？**
A：不要联网，不上传。系统不连任何外部服务（AI 草稿箱也是只收本地文件的接口）。
这也是本项目存在的意义：数据主权在诊所自己手里。

**Q：有云端备份吗？**
A：开源版只有本地备份（数据备份页 + 拷文件夹）。云端备份属于后期托管增值服务，
不在开源包里——想要的话关注项目主页。

## 局域网（iPad/手机）

**Q：iPad 打不开网址？**
A：按顺序查：① 启动时设了 `DENTAL_LOCAL_ONLY=0` 吗 ② iPad 和电脑连的是**同一个 WiFi** 吗
③ 黑窗口上打印的局域网 IP 对不对 ④ 电脑防火墙有没有拦 8765 端口（首次会弹窗，选允许）。

**Q：iPad 打开后要口令？**
A：这是防同 WiFi 陌生人乱入的。口令首启自动生成，存在 `data/.lan_password`；
想自己定就设环境变量 `DENTAL_ACCESS_PASSWORD`。

## 后台运行 / 开机自启

**Q：能不能不显示黑窗口、开机自动跑？**
A：能。做一个 `后台启动.vbs`（产品手册「后台运行 & 开机自启」一节有现成三行脚本），
双击就是无窗口后台跑；再把它的**快捷方式**放进「启动」文件夹（`Win + R` 输 `shell:startup`）
就能开机自启——注意放快捷方式，别把 `.vbs` 本体挪过去，本体一走它就找不到 exe 了。
想停：任务管理器里结束 `good-dental-clinic.exe`。
⚠️ 排查问题时请用黑窗口方式启动，后台方式看不到报错。

## 打印

**Q：病历/收费单怎么打印？**
A：病历卡、处置单、收费明细页都有打印入口（浏览器打印，选自家打印机）。
打印单头显示的是「全店设置」里填的诊所名。

## 升级

**Q：出新版本了怎么升？**
A：下载新版 exe → 停掉旧的 → 用新 exe 换掉旧的（`data` 文件夹别动）→ 启动。
建库结构有变化时系统启动会自动迁移，不用手工管。**升级前先在「数据备份」做个快照**，
万一不合意，停服务、换回去、恢复快照即可。

## 新增患者（建档）

**Q：建档窗口上出现「本浏览器禁用了本地存储，防重复建档保护不可用」，什么意思？**
A：系统给每次建档配了一个隐形的**单号**，记在浏览器里。万一点保存时网络卡了一下、
页面没收到回音，你关掉窗口重开再填一遍，系统凭这个单号认得出是同一单，会把上次
那位患者还给你，**不会建出两份档案**。

浏览器开了**无痕模式 / 隐私浏览**，或者设置里关掉了「允许网站保存数据」，这个单号
就记不住了，防重复保护失效——所以弹这行提醒。

碰到了怎么办：
- 最省事：关掉无痕窗口，用**普通窗口**重新打开系统，提醒就没了。
- 一定要在这个窗口建：**可以照常建**，但保存后如果页面没反应，先去患者列表搜一下
  这个人，确认没建上再重新提交，别连着点。

**Q：不小心建出两份重复档案了怎么办？**
A：患者列表里找到那一行 →「更多」→「合并患者」，把重复的那份并到正确的那份上，
病历、收费、影像都会跟着归到一起。这一步需要「患者资料·合并」权限（高风险操作，
一般只开给管理员），在「角色与权限」里配。

## 拍照建档（仅 macOS）

**Q：新增患者里没有「拍照识别」按钮？**
A：三个条件缺一就自动隐藏：① 必须是 macOS ② 用的是系统 Python 或装了
`requirements-ocr.txt` ③ 入口只对管理员/有建档权限的角色显示。Windows/Linux 没有这个功能。

**Q：识别错了怎么办？**
A：识别只是预填，保存前每个字段都能改；认不准的字段会标黄提醒核对。
身份证号认出来后，生日性别是从号码**算**出来的，比认的更准。

## AI 草稿箱

**Q：AI 草稿箱是空的，坏了吗？**
A：没坏。系统**不内置任何 AI**——它是个"收稿箱"：你自己用任何方式（语音管线、
任何大模型、手写脚本）生成病历草稿 markdown，丢进约定目录跑摄入命令，
医生在这里审核确认后才成为正式病历。接口格式见
[开源发布_AI草稿接口.md](开源发布_AI草稿接口.md)。不接 AI 时手写病历完全不受影响。

**Q：语音写病历什么时候有？**
A：语音管线属于后期托管增值服务，不在开源包里。关注项目主页。

## 其他

**Q：能多家诊所/连锁用吗？**
A：当前定位是**单店**（一台电脑 + 局域网）。连锁/多店是远期增值方向。

**Q：从其他 SaaS 诊所系统迁数据过来？**
A：开源版不含任何 SaaS 同步/迁移工具（刻意不带）。请从原系统导出后自行整理导入，
或找服务商定制迁移。
